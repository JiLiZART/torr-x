OPERATORS
field:value
equals (case-insensitive)
field:!value
not equal / negate
> < >= <=
numeric, size, date, speed
a..b
inclusive range
"two words"
quoted phrase, exact
*
wildcard inside text values
AND OR
explicit join · AND is implied by a space
( … )
grouping, one level in MVP
SORT — a predicate, never a column control
sort:ratio
default direction desc for numbers
sort:name asc
explicit direction
sort:state,ratio
multiple keys, left to right

RULES
·
An unknown field never silently returns nothing — it raises an inline error with a suggestion.
·
A lens is ANDed onto the tab query; the tab query is never rewritten.
·
Every surface renders the same chips for the same query string.
·
⌘C on the chip row copies the canonical query text.

INFORMATION ARCHITECTURE
Scope, Lens and Query are three different things
Three layers, one language. The sidebar holds scope, the tab holds a lens, and every surface speaks the same query. Nothing in this diagram lets a filter write to the sidebar except an explicit “Save as tab”.
Scope
a tab in the sidebar
WHAT
A saved query that defines which torrents exist in this view.
LIFETIME
Persistent. Survives restarts, sync and tab switches.
LIVES IN
Left sidebar. Pinned, ad-hoc, grouped, reorderable.
CREATED BY
“Save as tab” only — from the filter bar, builder, palette, Spotlight or terminal.
EXAMPLE
state:active tag:4k · tracker:xyz · added:>7d
Lens
an ephemeral filter
WHAT
An extra query ANDed onto the active tab's query.
LIFETIME
Ephemeral. Cleared when you switch tabs. Never written to the sidebar.
LIVES IN
The tab's filter bar, as chips that are always visible.
CREATED BY
Fuzzy input, filter builder, ⌘T “filter” results, terminal.
EXAMPLE
+ size:>4GB sort:ratio desc (inside tab “Active”)
Query
one shared language
WHAT
field:value predicates, AND/OR, negation, and sort — as text.
LIFETIME
None. It is a value: typed, parsed, rendered as chips, copied.
LIVES IN
Tabs, lens, builder, Spotlight, terminal, CLI, deep links.
GUARANTEE
One parser, one error model, one autocomplete source, one chip rendering.
EXAMPLE
state:active tag:4k size:>4GB sort:ratio desc

Scope store
persistent
Written only by “Save as tab”. One entry per sidebar tab. Rename, pin, group, reorder, sync.
Lens state
per tab, in memory
Dropped on tab switch unless saved. Rendered as chips next to the tab title. Undo-able.
Result set
derived
tab query AND lens → rows. Terminal prints the same rows the list shows.
Golden rule
A lens always scopes to the active tab. Global filtering happens only through ⌘T or the pinned “All” tab. Switching tabs clears the lens.
Never
Filtering must not mutate the sidebar. No hidden active filters. Sort is never a separate header control. Spotlight never mixes actions and filters inside one section.
